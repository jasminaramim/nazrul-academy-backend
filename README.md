# Trishal Nazrul Academy - Backend API

Express.js + MongoDB backend server for Nazrul Academy website.

## Setup

```bash
cd backend
npm install
cp .env.example .env  # .env ফাইলে আপনার credentials দিন
npm run dev
```

## API URL
- Local: http://localhost:3005/api
- Production: https://your-backend.vercel.app/api

## Deploy on Vercel
1. GitHub এ push করুন
2. vercel.com → New Project → এই repo import করুন
3. Environment Variables যোগ করুন (.env.example দেখুন)
4. Deploy!
